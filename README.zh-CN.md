# VZ-Redirect-Proxy

[English](README.md) | *简体中文* | [繁體中文](README.zh-TW.md)

一个极简、美观且功能丰富的**重定向中转页**。支持带参跳转、目标站点图标自动抓取、毫秒级倒计时动画、深浅色模式自适应，以及无参防滥用提示。

**在线体验：** `https://url-r.pages.dev`

## ✨ 核心特性

- **动态跳转**：通过 URL 参数 `?to=example.com` 动态设定目标网址。若未提供参数，页面会拒绝跳转，并提示“请通过好友分享的链接进入”。
- **毫秒级倒计时**：10 秒倒计时（保留 4 位小数），最后 3 秒页面背景平滑过渡为绿色，进度条颜色渐变，归零瞬间平滑黑屏并跳转。
- **图标智能抓取**：自动请求目标站点的 `favicon.ico`。深色模式下自动垫白底，防止黑色图标融入背景；如果目标站点无图标或请求超时，则优雅回退为“圆圈 i”字的内联 SVG。
- **快捷跳转**：提供“Go now”按钮（渐变亮蓝动效），点击后立即冻结倒计时、页面变灰并取消自动跳转，0.3 秒后直接前往目标站。
- **极致轻量**：全量代码都在单个 HTML 文件中，不依赖任何外部 CSS/JS 框架。原生支持深色/浅色模式（`prefers-color-scheme`）。

## 🚀 如何使用

### 1. 带参数跳转

直接通过链接分享，自动跳转至指定网站：

`https://url-r.pages.dev/?to=github.com`

*（支持无协议前缀，系统会自动补全 `https://`）*

### 2. 无参数访问

如果用户直接访问 `https://url-r.pages.dev/`（没有带 `to` 参数），页面会：

- 隐藏倒计时和跳转按钮。
- 标签页 `<title>` 变为 `Tip`。
- 显示提示语：“请通过好友分享的链接进入”。

### 3. 修改默认样式

在 `<style>` 的 `:root` 和 `@media (prefers-color-scheme: dark)` 中修改 CSS 变量，可快速定制主题色、按钮颜色（默认 `#33ACE9`）等。

## 🛠️ 技术细节

- **纯原生实现**：ES6 语法，使用 `requestAnimationFrame` 实现平滑倒计时。
- **防黑块 Favicon**：标签页图标硬编码为指定 SVG，通过替换 `fill` 颜色防深色模式黑块 Bug。
- **安全防范**：使用 `new URL()` 严格校验跳转参数协议（仅允许 `http/https`），并对图标抓取失败情况配置 3 秒超时降级，防止恶意参数导致页面卡死。
