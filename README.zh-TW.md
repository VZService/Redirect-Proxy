# VZ-Redirect-Proxy

[English](README.md) | [简体中文](README.zh-CN.md) | *繁體中文*

一個極簡、美觀且功能豐富的**重新導向中轉頁**。支援帶參數跳轉、目標網站圖示自動抓取、毫秒級倒數計時動畫、深淺色模式自適應，以及無參數防濫用提示。

**線上體驗：** `https://url-r.pages.dev`

## ✨ 核心特性

- **動態跳轉**：透過 URL 參數 `?to=example.com` 動態設定目標網址。若未提供參數，頁面會拒絕跳轉，並提示「請透過好友分享的連結進入」。
- **毫秒級倒數計時**：10 秒倒數計時（保留 4 位小數），最後 3 秒頁面背景平滑過渡為綠色，進度條顏色漸變，歸零瞬間平滑黑屏並跳轉。
- **圖示智慧抓取**：自動請求目標網站的 `favicon.ico`。深色模式下自動墊白底，防止黑色圖示融入背景；如果目標網站無圖示或請求逾時，則優雅回退為「圓圈 i」字的內聯 SVG。
- **快捷跳轉**：提供「Go now」按鈕（漸變亮藍動效），點擊後立即凍結倒數計時、頁面變灰並取消自動跳轉，0.3 秒後直接前往目標站。
- **極致輕量**：全量程式碼都在單個 HTML 檔案中，不依賴任何外部 CSS/JS 框架。原生支援深色/淺色模式（`prefers-color-scheme`）。

## 🚀 如何使用

### 1. 帶參數跳轉

直接透過連結分享，自動跳轉至指定網站：

`https://url-r.pages.dev/?to=github.com`

*（支援無協定前綴，系統會自動補全 `https://`）*

### 2. 無參數造訪

如果使用者直接造訪 `https://url-r.pages.dev/`（沒有帶 `to` 參數），頁面會：

- 隱藏倒數計時和跳轉按鈕。
- 分頁標籤 `<title>` 變為 `Tip`。
- 顯示提示語：「請透過好友分享的連結進入」。

### 3. 修改預設樣式

在 `<style>` 的 `:root` 和 `@media (prefers-color-scheme: dark)` 中修改 CSS 變數，可快速客製化主題色、按鈕顏色（預設 `#33ACE9`）等。

## 🛠️ 技術細節

- **純原生實現**：ES6 語法，使用 `requestAnimationFrame` 實現平滑倒數計時。
- **防黑塊 Favicon**：分頁標籤圖示硬編碼為指定 SVG，透過替換 `fill` 顏色防深色模式黑塊 Bug。
- **安全防範**：使用 `new URL()` 嚴格校驗跳轉參數協定（僅允許 `http/https`），並對圖示抓取失敗情況配置 3 秒逾時降級，防止惡意參數導致頁面卡死。
